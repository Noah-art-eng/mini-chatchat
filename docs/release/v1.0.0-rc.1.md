# Mini ChatChat v1.0.0-rc.1 Release Notes

Release date: 2026-08-05

## Summary

Mini ChatChat v1.0.0-rc.1 is the first public-demo release candidate. It packages the completed local RAG, search, temp file chat, Agent tools, MCP adapter foundation, user auth, user-scoped data, production Docker runtime, backup/restore, health checks, and release documentation into one deployable project.

## Highlights

- React product UI with Chat, Knowledge, Agent, Tool Center, System, and Account workspaces.
- Local KB RAG with hybrid search, metadata filter, context deduplication, and context token budget.
- Temp file chat and search engine mode.
- Conversation history with rename/delete, updated time sorting, feedback, and persisted assistant sources.
- Agent tool loop with calculator, current time, KB search, read-only SQLite, read-only filesystem, browser search/read, and MCP adapter foundation.
- Email auth, HttpOnly refresh cookies, session management, Google/GitHub OAuth integration, and user data isolation.
- Docker production compose with nginx proxy, health checks, user-scoped runtime volume, and backup/restore scripts.
- Smoke runner covering provider, chat, conversations, auth/session/OAuth, RAG, KB import/export, tools, Agent, MCP, and health.

## Security And Release Hardening

- Public `/health/deps` details are restricted in production by default.
- Frontend production dependency audit is clean.
- Backup archives now include checksum files.
- Restore requires explicit confirmation or `RESTORE_CONFIRM=yes`.
- HTTPS staging example is documented with Caddy.
- OAuth setup guide is documented for Google and GitHub.

## Breaking Changes

- `scripts/restore.sh` now requires explicit restore confirmation.
- The React frontend no longer depends on `react-router-dom`; it uses a small internal router for the existing navigation surface.

## Known Limits

- Real Google/GitHub OAuth callback verification requires live provider credentials.
- Public deployment still needs real HTTPS DNS, secret manager configuration, and production OAuth callback setup.
- Python dependency and Docker image vulnerability scanning are not automated in CI.
- Backend image remains large because local embedding dependencies are included.
- Backup encryption and off-host retention are documented but not implemented in scripts.
